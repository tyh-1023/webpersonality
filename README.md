# 互联网人格测试 · H5

一个纯静态的性格测试页面：25 道题，5 个维度，8 种「互联网人格」，测完生成可保存的结果海报。

- 无需后端、无需构建、无需 Node
- 手机优先，适配微信 / Safari / Chrome
- 答题进度自动保存在本地，刷新不丢

## 目录结构

```
index.html          入口页
app.js              人格数据、题目、计分、结果页、海报绘制
styles.css          全部样式（改配色看文件顶部的 CSS 变量）
vendor/qrcode.js    二维码库（qrcode-generator，MIT）
preview/            效果预览图
README.md           本文件
```

## 本地预览

**方式一（最简单）**：直接双击 `index.html`，用浏览器打开。

**方式二（推荐，行为最接近线上）**：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

## 上线前必须改的两处

1. **正式网址**：打开 `index.html`，把 `window.__SITE_URL__` 改成你的域名，例如
   `window.__SITE_URL__ = 'https://test.example.com/'`。
   海报上的二维码会固定指向它；留空则用当前页面地址。

2. **稀有度数字**：`app.js` 里每个人格的 `rarity` 目前是设定值（用于传播文案），
   不是真实统计。上线收集到足够样本后，建议用真实分布替换，或在结果页注明「模型估算」。

## 怎么改内容

| 想改什么 | 改哪里 |
| --- | --- |
| 人格名称、文案、颜色、匹配关系 | `app.js` 顶部的 `PERSONAS` |
| 题目、选项、维度 | `app.js` 的 `QUESTIONS` |
| 主色、背景、阴影 | `styles.css` 顶部的 `:root` 变量 |
| 首页标题、按钮文案 | `app.js` 的 `landingHTML()` |
| 计分规则 | `app.js` 的 `score()` |

每个人格的 `vector` 是五维坐标（活跃度 / 表达度 / 冲突度 / 探索度 / 痕迹度，0–100），
用户答完题后算出的五维得分会和 8 个向量比距离，最近的那个就是结果。

每道题有 4 个选项，每个选项带一个 0–100 的分数，代表它在所属维度上的强度。
某个维度的得分 = 该维度 5 道题所选分数的平均值。选项顺序是打乱的，不总是「从高到低」。

## 部署

### 方案 A：海外静态托管（最快，适合先跑起来）

Vercel / Netlify / Cloudflare Pages / GitHub Pages，把整个文件夹拖上去即可。
优点是免费、几分钟上线；缺点是国内访问速度不稳定，且**无法做 ICP 备案**。

### 方案 B：国内对象存储 + CDN（推荐正式发布）

阿里云 OSS / 腾讯云 COS 开启静态网站托管，上传四个文件，绑定已备案域名，开 CDN。
成本大约几元到几十元每月。

### 方案 C：国内轻量服务器 + Nginx

把文件放到 `/var/www/persona`，Nginx 指向该目录即可。灵活，但要自己维护和续费。

## ICP 备案流程（国内服务器必须）

1. 买域名（阿里云 / 腾讯云），实名认证。
2. 买一台国内服务器（一般要求剩余时长 ≥ 3 个月）。
3. 在服务器厂商的备案系统提交：主体信息、网站名称、网站内容、核验拍照。
4. 管局审核，通常 7–20 个工作日。
5. 备案号下来后，在页面底部放备案号，并链接到 `https://beian.miit.gov.cn`。
6. 上线 30 日内做公安联网备案。
7. 配置 HTTPS（厂商一般有免费证书）。

注意：个人备案只能做非经营性网站；「心理测试」类内容在备案时可能被要求补充说明，
网站名称不要出现「心理诊断」「治疗」「测评认证」等字样。

## 数据与隐私

当前版本**完全在前端运行**：不收集、不上传任何答题数据，答案只存在用户自己的
`localStorage` 里，所以不需要隐私政策。一旦你加入统计、后端、微信登录或问卷收集，
就必须补：隐私政策、收集告知、同意、最小必要、可删除。

## 预览参数（开发用）

在网址后加参数可以直接看某个状态，不影响正常用户：

- `?demo=quiz&q=6`：直接看第 6 题
- `?demo=result&type=contrarian`：直接看「杠精」结果页
- `?demo=poster&type=lurker`：直接看海报弹层
- `?demo=rawposter&type=mayor`：直接渲染 1080×1440 的原始海报

人格 id：`lurker` `liker` `contrarian` `ghost` `archaeologist` `reposter` `mayor` `drifter`

## 合规提醒

- 定位是娱乐与自我探索，不要宣称「心理诊断」「专业测评」「最准」。
- 不要用 MBTI 作为产品名（MBTI 是注册商标），文案里做说明性提及没问题。
- 小红书站内不能直接放外链，私信发链接属于导流，有限流和封号风险；
  H5 更适合放在群聊、公众号、个人主页等合规位置。
- 题目和文案请保持原创，不要照搬 16Personalities、才储等平台的题库。
